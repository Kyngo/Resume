% ---- Fonts ----------------------------------------------------------
% Fonts are loaded BY FILENAME on purpose. Do not "simplify" this to
% \setsansfont{Ubuntu}.
%
% Modern distros ship Ubuntu as a VARIABLE font (Ubuntu[wdth,wght].ttf).
% Selecting that family by name has two failure modes, both nasty:
%   1. fontspec cannot derive bold/italic from the family name, so every
%      \textbf silently degrades to regular weight -- only a warning, so a
%      wrong-looking PDF still builds successfully.
%   2. xdvipdfmx cannot embed variable fonts at all and dies with
%      "xdvipdfmx:fatal: Invalid font: -1 (0)", leaving a 15-byte stub PDF
%      while xelatex itself reports no LaTeX error.
% The static Ubuntu 0.83 faces (Ubuntu-R/B/RI/BI.ttf) are what the CI job
% pulls from assets.ubuntu.com and they embed correctly. Falls back to
% DejaVu Sans so this still builds on a machine without them.
\usepackage{fontspec}
% \IfFileExists checks the project-local fonts/ directory directly, without
% relying on the system fontconfig database (which won't see fonts that
% were only copied into fonts/ without fc-cache).
\IfFileExists{fonts/Ubuntu-R.ttf}{%
  \setsansfont{Ubuntu-R.ttf}[
    Path           = fonts/,
    BoldFont       = Ubuntu-B.ttf,
    ItalicFont     = Ubuntu-RI.ttf,
    BoldItalicFont = Ubuntu-BI.ttf,
  ]%
}{%
  \IfFontExistsTF{DejaVu Sans}{\setsansfont{DejaVu Sans}}{}%
}

\section*{Summary}
Platform Engineer with nearly 9 years of continuous experience. I build the internal
tooling, CI/CD pipelines and dashboards that every engineering team at TUI Musement
(\textasciitilde200 engineers, \textasciitilde800 repositories) ships on. I grew into platform
work from full-stack delivery and AWS operations, so the platforms I build are shaped by
having been on the receiving end of them. \textbf{Moving production systems without
disrupting them is the thread through my career}: two services between AWS accounts with
zero downtime, several off VPS hosting onto AWS with seconds of downtime, and an
\textasciitilde800-repository estate onto self-managed GitLab in phases. Security Champion
since 2024; currently building AI agents on AWS Bedrock.
